# 大润发到店购入口 - 商城 App 前端对接说明

> 适用端：商城用户 App（H5 / 小程序 / 原生均可，下统称 App）  
> 后端接口归属：`mall-server`（trade 模块 BFF）  
> 设计文档：`docs/superpowers/specs/2026-08-28-saas-mall-rtmart-home-entry-design.md`

## 1. 接口概述

登录用户在商城点击「大润发扫码购」时，App 调用本接口换取大润发到店购首页 H5 地址（`entryUrl`），再用 WebView 打开该地址进入到店购流程。

- App **只调商城**，**不得**直连供应链中台 `/rpc-api/supply-chain/**`。
- 用户身份由商城后端从登录态自动处理，App **无需**在请求体传手机号、姓名、token、`companyCode`、`buyerUserId` 等任何用户信息。
- 请求体只承载当前定位坐标（经纬度）。

## 2. 请求信息

| 项 | 值 |
|---|---|
| 请求地址 | `POST /app-api/trade/instore/rtmart/home-entry` |
| 请求方法 | `POST` |
| Content-Type | `application/json` |
| 认证方式 | 需登录，请求头携带 `Authorization: Bearer <accessToken>` |
| 访问日志 | 后端已关闭该接口访问日志，坐标与返回 URL 不会入库 |

> `<accessToken>` 为 App 登录接口返回的访问令牌；未携带或令牌失效时由安全过滤器返回 `401`，本接口本身不返回未登录错误。

## 3. 请求参数

请求体为 JSON 对象，仅含经纬度两个字段：

| 字段 | 类型 | 必填 | 约束 | 说明 |
|---|---|---|---|---|
| `longitude` | string | 是 | 非空，最长 32 字符 | 经度，字符串形式，如 `"121.4737"` |
| `latitude` | string | 是 | 非空，最长 32 字符 | 纬度，字符串形式，如 `"31.2304"` |

> 经纬度必须为字符串类型，不要传数值类型。字段语义与中台位置字段一致，用于就近匹配到店门店。

请求示例：

```json
{
  "longitude": "121.4737",
  "latitude": "31.2304"
}
```

## 4. 响应结构

响应体为商城统一返回结构 `CommonResult<T>`：

| 字段 | 类型 | 说明 |
|---|---|---|
| `code` | integer | `0` 表示成功，非 `0` 表示业务错误（错误码见第 5 节） |
| `data` | object / null | 成功时为响应数据对象，失败时为 `null` |
| `msg` | string | 成功为空，失败为错误提示文案 |

### 4.1 成功响应

`data` 对象字段：

| 字段 | 类型 | 说明 |
|---|---|---|
| `entryUrl` | string | 大润发到店购首页入口 H5 地址，由商城原样转发中台结果 |

成功示例：

```json
{
  "code": 0,
  "data": {
    "entryUrl": "https://example.com/instore/entry?token=CXB_xxx"
  },
  "msg": ""
}
```

### 4.2 失败响应

```json
{
  "code": 1011011000,
  "data": null,
  "msg": "到店购入口未配置，请联系管理员"
}
```

## 5. 错误码

| 错误码 | 含义 | 前端建议处理 |
|---|---|---|
| `0` | 成功 | 打开 `entryUrl` |
| `401`（HTTP 状态） | 未登录 / 令牌失效 | 引导用户重新登录后重试 |
| `1_011_011_000` | 到店购入口未配置，请联系管理员 | 提示用户联系管理员，通常为后端项目应用凭证缺失 |
| `1_011_011_001` | 到店购入口暂不可用，请稍后重试 | 中台返回空地址，提示稍后重试 |
| `1_011_011_002` | 到店购入口暂不可用，请稍后重试 | 中台或网络异常，提示稍后重试 |
| 中台透传错误码 | 中台业务错误原样回传 | 展示 `msg` 文案即可 |

> `1_011_011_001` 与 `1_011_011_002` 文案相同，前端可统一按「稍后重试」处理，无需区分。

## 6. 调用流程

1. **确认登录态**：调用前确保已登录并持有有效 `accessToken`，否则先走登录流程。
2. **获取定位**：获取当前设备经纬度（字符串形式）。无定位权限时按 App 既有定位缺省策略处理（如引导授权或传默认值，由业务决定）。
3. **调用接口**：`POST /app-api/trade/instore/rtmart/home-entry`，请求头带 `Authorization: Bearer <accessToken>`，请求体带经纬度。
4. **处理响应**：
   - `code === 0`：取 `data.entryUrl`，用 WebView 打开。
   - `code !== 0`：展示 `msg` 文案，按第 5 节建议处理。
5. **打开 WebView**：直接加载 `entryUrl`，进入大润发到店购 H5 流程。

## 7. 注意事项

1. **`entryUrl` 不可改写**：URL 内含旅通短期凭证（`CXB_` token），App 不得改写、拼接参数、二次加前缀或截断，必须原样加载。
2. **不可缓存**：`entryUrl` 为短期有效地址，每次进入到店购都应重新请求获取，禁止本地缓存复用。
3. **不传用户信息**：请求体禁止出现 `companyCode`、`buyerUserId`、手机号、姓名、token 等；用户身份由商城后端通过 HMAC 认证头透传中台，App 无需也无法传递。
4. **不直连中台**：App 不得调用 `/rpc-api/supply-chain/**`，所有到店购入口一律走商城本接口。
5. **经纬度类型**：必须为字符串，传数值类型会被校验拒绝。
6. **安全提示**：`entryUrl` 属敏感地址，App 不应将其写入业务日志、埋点明文或分享链接。

## 8. 前端调用示例

### 8.1 axios 示例

```javascript
import axios from 'axios'

/**
 * 获取大润发到店购首页入口地址
 * @param {string} accessToken 登录令牌
 * @param {string} longitude 经度（字符串）
 * @param {string} latitude  纬度（字符串）
 * @returns {Promise<string>} entryUrl 到店购 H5 入口地址
 */
export async function getRtmartHomeEntry(accessToken, longitude, latitude) {
  const { data } = await axios({
    method: 'POST',
    url: '/app-api/trade/instore/rtmart/home-entry',
    headers: {
      'Content-Type': 'application/json',
      Authorization: `Bearer ${accessToken}`
    },
    data: { longitude: String(longitude), latitude: String(latitude) }
  })

  if (data.code !== 0) {
    // 业务错误，抛出或按错误码分支处理
    throw new Error(data.msg || '到店购入口暂不可用，请稍后重试')
  }
  return data.data.entryUrl
}

// 调用
getRtmartHomeEntry(accessToken, '121.4737', '31.2304')
  .then((entryUrl) => {
    // 用 WebView 打开 entryUrl
    openWebView(entryUrl)
  })
  .catch((err) => {
    // 提示 err.message
    showToast(err.message)
  })
```

### 8.2 uni-app / 小程序示例

```javascript
uni.request({
  url: '/app-api/trade/instore/rtmart/home-entry',
  method: 'POST',
  header: {
    'Content-Type': 'application/json',
    Authorization: `Bearer ${accessToken}`
  },
  data: { longitude: String(longitude), latitude: String(latitude) },
  success(res) {
    const body = res.data
    if (body.code === 0) {
      // web-view 页面打开 entryUrl
      uni.navigateTo({ url: `/pages/webview/index?url=${encodeURIComponent(body.data.entryUrl)}` })
    } else {
      uni.showToast({ title: body.msg || '到店购入口暂不可用，请稍后重试', icon: 'none' })
    }
  },
  fail() {
    uni.showToast({ title: '网络异常，请稍后重试', icon: 'none' })
  }
})
```

## 9. 联调与排障

- 联调步骤、前置条件与验证点见 `docs/集成测试.md`「大润发到店购入口」章节。
- 常见问题：
  - 返回 `1_011_011_000`：后端未配置项目应用凭证（`appId`/`appKey`），联系后端检查 `aifuli.mall.instore.project-app` 配置。
  - 返回 `401`：`accessToken` 缺失或失效，重新登录。
  - 返回 `1_011_011_002`：中台不可达或上游异常，联系后端排查中台与 Nacos 服务发现。

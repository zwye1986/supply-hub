# 供应链管理端开票查询与保存 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为供应商、分销商提供 `GET/PUT …/{code}/invoice`：无行预填不落库，保存明文开票表且不回写档案。不改前端。

**Architecture:** Liquibase `023-admin-invoice` 建 1:1 表。校验与预填规则集中在 `tradecore.profile`；查询/保存分属 `SupplierInvoiceService` / `BuyerInvoiceService`。Controller 只映射 REST 与权限。开户账号明文存开票表；预填时才解密档案密文。

**Tech Stack:** Spring MVC、MyBatis Plus、Liquibase、JUnit 5、Testcontainers MySQL 8.4。JDK 21：`/Library/Java/JavaVirtualMachines/jdk-21.jdk/Contents/Home`。

**Spec:** `docs/superpowers/specs/2026-09-07-供应链管理端开票信息设计.md`

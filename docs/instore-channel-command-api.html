1签名规则（SHA1withRSA）

所有接口共用同一签名规则，与"获取会员信息"接口①完全一致。

规范串生成：取除 sign 外的所有非 null 字段，按 字段名字典序 升序排列，依次拼接 key + value（无任何分隔符），对 UTF-8 字节以 旅通私钥 执行 SHA1withRSA 签名，标准 Base64 编码即 sign。

2创建订单（接口②）

请求地址

POST http://apitest.kalaiwang.com/api/rtmart/order/create

请求参数

参数名称类型必传描述
app_keyStringY授权key
versionStringY等级
timestampIntegerY请求日期（时间戳，秒）
nonce_strStringY随机数
signStringY签名
order_idStringY中台订单号
trade_idStringY中台支付流水号
user_codeStringY会员编号
company_codeStringY企业组编号
total_amountIntegerY应付金额，单位：分
order_timeIntegerY支付单创建时间，单位：秒
order_typeIntegerY支付单类型：当前仅支持 1（线下扫码购）；其他值返回 E4001
shop_codeStringY门店编号
shop_nameStringY门店名称

请求示例

{
  "app_key": "1G23d45P6",
  "version": "v1",
  "timestamp": 1744191949,
  "nonce_str": "5KfeeG8vVAXpp734",
  "sign": "base64-encoded-signature==",
  "order_id": "RT-ORDER-001",
  "trade_id": "RT-TRADE-001",
  "user_code": "247",
  "company_code": "X0000A",
  "total_amount": 1650,
  "order_time": 1744191948,
  "order_type": 1,
  "shop_code": "1001",
  "shop_name": "宜山路店"
}

成功响应

{
  "result": "success",
  "code": "E0000",
  "msg": "",
  "data": {
    "out_trade_no": "IPF_OTN_001",
    "cashier_url": "https://cashier.example.com/pay?token=xxx"
  }
}

响应参数

参数名称类型描述
resultString接口状态，success为成功
codeString状态码，E0000为成功
msgString状态描述
data.out_trade_noString商户支付单号
data.cashier_urlString收银台地址（处理中可能为空，需按out_trade_no查询）

5申请退款（接口⑤）

请求地址

POST http://apitest.kalaiwang.com/api/rtmart/refund/apply
Pos推送退款到商城，商城转发到商户。商户处理退款，需支持多次退款。

请求参数

参数名称类型必传描述
app_keyStringY授权key
versionStringY等级
timestampIntegerY请求日期（时间戳，秒）
nonce_strStringY随机数
signStringY签名
order_idStringY订单号
trade_idStringY支付流水号
refund_bnStringY退款单号
refund_feeIntegerY退款金额，单位：分
user_codeStringY会员编号
company_codeStringY企业组编号

成功响应

{
  "result": "success",
  "code": "E0000",
  "msg": "",
  "data": {
    "out_trade_no": "IPF_001",
    "out_refund_no": "IRC_001",
    "refund_status": 0,
    "refund_fee": 580,
    "refund_time": 1736735103,
    "refuse_reason": ""
  }
}

响应参数

参数名称类型描述
data.out_trade_noString商户支付单号
data.out_refund_noString商户退款单号
data.refund_statusInteger退款状态：0 待退款或处理中，1 退款成功，2 退款失败。受理成功通常为 0
data.refund_feeInteger退款金额，单位：分；取本次请求金额
data.refund_timeInteger退款时间，单位：秒。受理时无完成时间，填接口调用当前时间；键必须输出
data.refuse_reasonString退款失败原因；没有时填空字符串，禁止 null 或省略

signStringY签名
order_idStringY订单号
trade_idStringY支付流水号

7错误码

状态码说明描述
E0000成功
E4001请求参数缺失或非法公共/业务必填字段缺失或非法、nonce 重放、可由调用方修正的业务拒绝
E4002请求已过期timestamp 与服务端时钟偏差超过三分钟窗口（默认 ±180 秒，可配置）
E4003app_key 不正确app_key 与服务端配置的期望值不匹配
E4004签名验证失败sign 缺失、为空或 SHA1withRSA 验签不通过
E5000系统错误Redis/收银台/内部配置等服务异常及未知异常（fail-closed）

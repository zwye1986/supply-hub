1接口概述

本接口由供应链中台实现，供旅通（大润发到店购渠道）在用户打开入口页时回调，凭中台签发的短期授权 token 换取会员资料（会员编号、手机号、姓名、企业组编码）。

项目说明
接口地址POST http://apitest.kalaiwang.com/api/rtmart/member/resolve
base_url 为 http://apitest.kalaiwang.com（公网网关 nginx 反代 pro143:58190）；内网调试可用 http://127.0.0.1:58190 同路径
Content-Typeapplication/json
调用方外部
认证方式旅通协议 SHA1withRSA 签名（app_key + sign，标准 Base64），免登录端点
幂等性否 — token 为一次性凭证，消费后转为 USED，不可重放
失败可重试会员资料暂时不可用 / 并发冲突时可用同一 token 重试（凭证会被释放回 ACTIVE）
对应旅通文档「接口① 获取会员信息 — 商户提供接口地址，旅通调用」
协议要点：本接口的请求/响应字段命名、签名算法、错误码体系均遵循旅通协议（snake_case 字段、SHA1withRSA 签名、E0000 成功码），与中台内部 RPC（HMAC-SHA256 + CommonResult）完全不同。旅通侧无需理解中台内部协议。

2请求规格

2.1 请求体字段

参数名称类型必传描述
app_keyStringY授权 key。服务端将其与配置的期望值比对，同时映射为中台 projectId + channelCode，任何请求不得携带其他身份字段
versionStringY协议等级/版本号，参与签名
timestampIntegerY请求日期（Unix 秒时间戳）。服务端校验与服务时钟偏差 ≤ 300 秒（可配置）
nonce_strStringY随机数，参与签名
signStringYSHA1withRSA 签名（标准 Base64 编码，旅通 1024 位密钥约 172 字符），生成规则见第 3 节
tokenStringY授权 token。取自中台签发的 entryUrl 中 token 查询参数（含 CXB_ 前缀，服务端会自动剥离）

3签名规则（SHA1withRSA）

签名对除 sign 外的全部非空请求字段计算，步骤如下：

Step 1
取除 sign 外的所有字段：app_key、version、timestamp、nonce_str、token；timestamp 转为十进制字符串
Step 2
按 字段名字典序升序排列：app_key < nonce_str < timestamp < token < version
Step 3
依次拼接 key + value（无任何分隔符、无 &/=、无换行）得到规范串
Step 4
以旅通私钥对规范串 UTF-8 字节执行 SHA1withRSA（即 RSASSA-PKCS1-v1_5 + SHA-1）签名
Step 5
签名字节以标准 Base64 编码（含填充，非 Base64URL）即 sign

密钥方向：中台调用旅通（出站 getRtPosUrl）时以中台私钥签名、旅通用中台公钥验签；旅通回调本接口（入站）时以旅通私钥签名、中台用旅通公钥验签。两侧算法同为 SHA1withRSA + Base64、规范串同为字典序 key+value 拼接，但密钥对不同，不可混用。
常见签名失败原因：① 规范串末尾混入换行符（如 shell echo 追加的 \n，须用 printf '%s'）；② timestamp 参与签名时未转为字符串；③ 误用 MD5/SHA256 摘要代替 RSA 签名；④ 签名后误用 Base64URL 或漏掉填充。签名失败统一返回 E4003 签名验证失败，不区分具体原因。

5错误码

5.1 适配器层错误（协议校验阶段）

codemsg触发条件
E4001请求参数缺失六个必填字段任一为空或缺失
E4002请求已过期timestamp 与服务端时钟偏差超过容差（默认 ±300 秒）
E4003app_key 不正确app_key 与服务端配置的期望值不匹配
E4004签名验证失败sign 缺失、为空或 SHA1withRSA 验签不通过（字段缺失、排序错误、规范串换行、篡改、密钥不配对）
E5000服务未开启服务端入站适配器开关为关闭状态（fail-closed）

5.2 业务层错误（中台错误码 → 旅通错误码映射）

codemsg中台错误码触发条件可否重试
E4001授权凭证或会员资料无效1_050_001_036/037/038/043凭证无效、过期、已消费或已撤销（终态）否（重新走入口）
E4001授权凭证或会员资料无效1_050_001_039凭证租户作用域冲突否
E4001授权凭证或会员资料无效1_050_001_041凭证 CAS 状态推进失败（并发抢占）同 token 重试
E4001授权凭证或会员资料无效1_050_001_044会员解析 NOT_FOUND 或手机号为空；凭证已释放回 ACTIVE同 token 重试
E5000会员资料暂时不可用1_050_001_045SaaS 会员服务外呼 UNAVAILABLE / 超时 / 网络异常；凭证已释放回 ACTIVE同 token 重试
E5000系统错误—未分类的运行时异常（内部日志保留完整因果链）否
重试语义：会员查询是只读操作。响应码已统一为六个确认码：凭证终态（无效/过期/已消费/已撤销）与租户作用域冲突均返回 E4001，重试必然失败，应引导用户重新走入口流程；并发冲突与会员资料无效同样返回 E4001，但中台已将凭证释放回 ACTIVE（未过期前提），允许旅通用同一 token 原样重试；E5000（会员资料暂时不可用）亦可同 token 重试。旅通无法仅凭 code 区分终态与可重试场景，建议对 E4001 优先引导重新走入口流程，确属并发或资料问题时再同 token 重试。

6完整调用流程

①
大润发调用 getHomeUrl（HMAC-SHA256 认证，BUYER_USER_ID scope）请求中台生成到店购入口
②
中台签发短期凭证 — 写入 instore_entry_credential（状态 ACTIVE），token 明文形如 tk-xxxx，有效期与用途（HOME）冻结
③
中台外呼旅通 getRtPosUrl/home — 携带 token（SHA1withRSA 签名，出站协议）
④
旅通返回 jump_url — token 被加上 CXB_ 前缀拼入 entryUrl 查询参数
⑤
用户浏览器打开 entryUrl — 旅通 H5 页面需要会员信息以继续扫码购流程
⑥
旅通回调本接口 — 从 entryUrl 取出 token，组装六字段请求并以旅通私钥计算 SHA1withRSA 签名
⑦
适配器协议校验 — 必填检查 → app_key 匹配 → 时间戳容差 → SHA1withRSA 验签（旅通公钥） → 剥离 CXB_ 前缀
⑧
凭证认领 — 按 token SHA-256 摘要定位凭证，校验项目/渠道/用途后 CAS 抢占 ACTIVE → PROCESSING
⑨
冻结路由解析 — 使用凭证签发时冻结的 MEMBER_PROFILE 路由版本（不受后续档案变更影响）
⑩
SaaS 会员外呼 — Feign 调用会员服务，按 (sourceSystem, externalTenantId, buyerUserId) 三元组解析手机号/姓名
⑪
凭证终态 — 成功则 CAS 标记 USED；失败则释放回 ACTIVE（可重试）或转 EXPIRED/REVOKED
⑫
返回旅通协议响应 — 组装 result/code/msg/data（snake_case），user_code = buyer_user_id

7凭证状态机

ACTIVE → PROCESSING → USED
状态数值含义允许的后续流转
ACTIVE10已签发待消费认领为 PROCESSING；到期转 EXPIRED；档案退役转 REVOKED
PROCESSING15已被某次回调抢占，会员外呼进行中成功 → USED；失败释放 → ACTIVE；释放时已过期 → EXPIRED
USED20消费成功，终态无（一次性语义，重放返回 E4004）
EXPIRED30超过有效期，终态无
REVOKED40冻结档案退役被撤销，终态无
并发抢占：同一 token 的并发回调只有一个能完成 ACTIVE → PROCESSING 的 CAS 抢占，其余立即收到 E4001（并发冲突，映射为 INVALID_ARGUMENT）。抢占成功者超时未完成时凭证由释放路径恢复，不会永久卡在 PROCESSING。

8安全约束

约束说明
token 一次性消费凭证成功消费后转 USED 终态，任何重放请求返回 E4004，即使签名正确
时间戳容差默认 ±300 秒（可配置），阻断过期请求重放；服务时钟需保持 NTP 同步
身份三元组不可注入会员外呼的 (sourceSystem, externalTenantId, buyerUserId) 全部来自凭证签发时冻结的数据与冻结路由，请求方无法通过任何字段注入身份
个人信息不落库mobile / userName 仅在本次调用内存中短暂存在并转发，中台数据库只存 token 的 SHA-256 摘要
日志脱敏服务端日志禁止出现 token、手机号、姓名、userCode；仅记录路由摘要、结果分类与耗时；响应 DTO 以 @ToString.Exclude 防止意外输出
渠道隔离app_key 唯一映射到一个 projectId + channelCode，禁止跨项目共享；company_code 仅作为供应商绑定标识，不承担采购商身份识别
fail-closed适配器开关关闭时所有请求返回 E5000，不会降级为跳过验签

12附录：Python 调用示例

Python 标准库不支持 RSA 签名，示例通过 openssl 命令行完成 SHA1withRSA 签名（对应 Java Signature.getInstance("SHA1withRSA")；注意输入必须无尾部换行）：

import base64
import json
import secrets
import subprocess
import time
import urllib.request

BASE_URL = "http://apitest.kalaiwang.com"      # 对外网关（nginx 反代 pro143:58190）
APP_KEY = "1G23d45P6"
VERSION = "1"
PRIVATE_KEY_PEM = "/path/to/rtmart-private.pem"   # 旅通侧私钥（测试模拟用）

def sha1with_rsa_sign(canonical: str) -> str:
    """对规范串执行 SHA1withRSA 签名并返回标准 Base64。"""
    proc = subprocess.run(
        ["openssl", "dgst", "-sha1", "-sign", PRIVATE_KEY_PEM],
        input=canonical.encode("utf-8"),      # 无尾部换行，切勿用 echo 管道
        capture_output=True, check=True,
    )
    return base64.b64encode(proc.stdout).decode("ascii")

def resolve_member(token: str) -> dict:
    """按旅通协议签名并调用获取会员信息接口。

    token: entryUrl 查询参数中的原始值（含 CXB_ 前缀），原样参与签名。
    """
    timestamp = int(time.time())              # Unix 秒
    nonce_str = secrets.token_hex(16)         # 32 位小写十六进制随机数

    # 参与签名的字段：除 sign 外全部非空字段（timestamp 转字符串）
    fields = {
        "app_key": APP_KEY,
        "nonce_str": nonce_str,
        "timestamp": str(timestamp),
        "token": token,
        "version": VERSION,
    }
    # 按 key 字典序排序后 key+value 拼接（无分隔符），再 SHA1withRSA + Base64
    canonical = "".join(k + v for k, v in sorted(fields.items()))
    sign = sha1with_rsa_sign(canonical)

    body = json.dumps({
        "app_key": APP_KEY,
        "version": VERSION,
        "timestamp": timestamp,
        "nonce_str": nonce_str,
        "sign": sign,
        "token": token,
    }).encode("utf-8")

    request = urllib.request.Request(
        f"{BASE_URL}/api/rtmart/member/resolve",
        data=body,
        headers={"Content-Type": "application/json"},
        method="POST",
    )
    with urllib.request.urlopen(request, timeout=15) as response:
        return json.loads(response.read())

if __name__ == "__main__":
    token = "CXB_tk-38efcf236aacdb0cfa5af080095090ff281f2d3bebe39831a6d44157ea5c6021"
    print(json.dumps(resolve_member(token), indent=2, ensure_ascii=False))

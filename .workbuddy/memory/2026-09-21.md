# 2026-09-21 工作日志

## 项目全貌理解

对 supply-hub 仓库做了系统性通读，建立项目整体认知：

- **仓库性质**：从 mall-pro 拆分出的供应链中台独立仓库，已删除 pay/erp/mall/statistics 模块。基于芋道(aifuli-cloud) Spring Cloud 微服务框架，JDK 21 + Spring Boot 3.5.9。
- **8 个可独立启动进程**：GatewayServerApplication、AifuliServerApplication(system+infra聚合,member依赖已注释)、SystemServerApplication、InfraServerApplication、MemberServerApplication、SupplyChainServerApplication、TaobaoFlashChannelApplication、MovieServerApplication。
- **核心业务**：供应链中台，管理采购商(Buyer)/供应商(Supplier)/标准商品池/采购订单(BuyerOrder)/供应商履约尝试(SupplierOrder)/采购资金唯一账本/多场景履约。
- **多场景**：CARD(卡券/直充)、O2O(淘宝闪购/盒马)、INSTORE(大润发到店购)、Movie(电影票务,独立MongoDB)。
- **供应链模块内部分层**（com.aifuli.module.supplychain 下）：
  - border：场景边界(order/fulfillment/o2o/instore/rtmart)
  - tradecore：交易核心(catalog/supply/buyer/account/ledger/profile)
  - routing：纯计算路由与决策快照(domain不依赖Spring)
  - supplieradapter：供应商适配器(qnm等)
  - infrastructure：基础设施(outbox/inbox/timer/security/auth/identity/time)
  - integration：外部集成(taobaoflash/saasmall/rtmart/buyer/system)
  - application：应用层facade
  - interfaceapi：admin REST + RPC
- **严格边界约束**：供应链独立数据源supplyChainDataSource、独立事务管理器supplyChainTransactionManager、表名sc_*前缀无物理外键、ArchUnit(SupplyChainModuleArchitectureTest)强制分层。
- **关键设计文档**：docs/superpowers/specs/ 下有核心设计、拆仓设计、PRD范围对齐、采购商项目化设计等；docs/adr/ 有6个到店购独立于O2O的架构决策记录。
- **领域词汇表**：仓库根 CONTEXT.md 定义了完整的统一语言(Buyer/Supplier/PlatformProduct/SupplierOffer/ProjectListing/三级结算价等)。

## 供货配置返回商品分类 id 方案调研

- 接口：`GET /admin-api/supply-chain/suppliers/{supplierCode}/supply-scopes` → `SupplierProfileQueryService.listSupplyScopes` → `toScopeViews`
- `SupplyScopeView.productClassification` 语义（d34）：封闭枚举名（ELECTRONICS/VIRTUAL_CARD/MOVIE_TICKET）或 `sc_product_category.category_code`
- `sc_product_category` 有内部主键 id 和 categoryCode；`ProductClassificationValidationService.requireWritable` 已有编码→类目行解析（含 expectedCategoryId 一致性校验）
- `toScopeViews` 是批量装配（modesByScopeId 一次查），新增 categoryId 解析可复用同模式；该方法被 listSupplyScopes / get 详情 / toListItem 列表三处复用
- 核心设计约束：内部包只能通过 Interface 协作，禁止跨包访问 DAO/Mapper → supply 包应通过 catalog 应用服务批量解析，不直接注入 ProductCategoryMapper

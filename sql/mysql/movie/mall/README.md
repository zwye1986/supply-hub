# 已废弃的商城电影扩展方案

2026-09-17 起，电影订单采用独立电影业务订单与中台统一订单双端落库，不再使用 `trade_order`、`trade_order_movie` 或其它商城交易表。

本目录 SQL 和 changelog 仅保留历史追溯，不作为当前电影部署入口。不要按旧说明执行本目录迁移，也不要为了清理旧方案删除已有交易表或修改已执行 changeset 的 checksum。

现行字段、索引、状态、两库职责和后续迁移范围见 [电影订单独立存储设计](../../../../docs/superpowers/specs/2026-09-17-movie-order-storage-design.md)。新表尚未接入可执行迁移；已有历史数据如需迁移，应先清点并单独设计。

# 电影 RPC 契约模块

本模块位于仓库根目录，直接继承根 POM。当前提供服务寻址常量和接口、DTO、枚举的包结构，后续按
[详细设计](../docs/电影子系统与中台履约详细设计.md)第 4.2、4.4 节实现稳定契约。

- 服务名：`movie-server`；RPC 前缀：`/rpc-api/movie`。
- 商城、供应链中台只能依赖本 API 模块，不能依赖电影 Server 或扫描其实现包。
- 调用方使用仓库统一版本 `${revision}`，并通过 `@EnableFeignClients(clients = {...})` 显式注册实际使用的接口。
- 电影金额使用人民币元 `BigDecimal`；DTO 不包含商城积分、租户定价或供应商密钥。
- DTO 字段涉及 MySQL 表时，注释与相应 DDL `COMMENT` 的业务含义保持一致。
